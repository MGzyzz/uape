# UAPE — Образовательная платформа

UAPE — это веб-платформа для обучения программированию. Агрегирует курсы, плейлисты и каналы с YouTube, подбирает контент под каждого пользователя на основе его интересов и уровня подготовки.

---

## Что нужно установить заранее

Перед началом убедитесь, что на компьютере установлено:

| Программа | Зачем | Где скачать |
|-----------|-------|-------------|
| **Python 3.11+** | Запуск сервера | https://www.python.org/downloads/ |
| **Node.js 18+** | Запуск интерфейса | https://nodejs.org/ |
| **Poetry** | Управление пакетами Python | https://python-poetry.org/docs/#installation |
| **Git** | Скачать проект | https://git-scm.com/ |

> **Проверка:** Откройте терминал и введите `python3 --version`, `node --version`, `poetry --version`. Если показывает версии — всё установлено.

## Установка проекта

### Шаг 1. Скачать проект

```bash
git clone <ссылка-на-репозиторий>
cd uape
```

---

### Шаг 2. Настройка бэкенда (сервер)

```bash
cd back_end
```

**Установить зависимости:**
```bash
poetry install
```

**Создать файл `.env`** в папке `back_end/`, скопировав пример:
```bash
cp .env.example .env
```

Затем открыть `.env` и заполнить значения (подробнее — в разделе [Переменные окружения](#переменные-окружения) ниже).

**Применить миграции (создать базу данных):**
##### Примечание: Если у вас операционная система Windows, то используется команду **python** 
```bash
python3 manage.py migrate
```

**Создать аккаунт администратора:**
```bash
python3 manage.py createsuperuser
```
Введите имя пользователя, email и пароль — они нужны для входа в панель управления.

**Заполнить базу данных начальными данными:**
```bash
python3 seed_sections.py
```

---

### Шаг 3. Настройка фронтенда (интерфейс)

```bash
cd ../front_end
```

**Установить зависимости:**
```bash
npm install
```

**Создать файл `.env`** в папке `front_end/` со следующим содержимым:
```
VITE_API_URL=/api
VITE_GOOGLE_CLIENT_ID=ваш_google_client_id
```

> `VITE_GOOGLE_CLIENT_ID` — тот же Client ID, что в бэкенде (см. ниже). Нужен для кнопки "Войти через Google".

---

## Запуск

Нужно запустить **два** процесса одновременно — в двух отдельных окнах терминала.

**Терминал 1 — сервер (бэкенд):**
```bash
cd back_end
poetry run python3 manage.py runserver
```
Сервер запустится на http://localhost:8000

**Терминал 2 — интерфейс (фронтенд):**
```bash
cd front_end
npm run dev
```
Интерфейс откроется на http://localhost:5173

## Переменные окружения

Файл `back_end/.env` содержит все секретные ключи и настройки. Ниже объяснение каждого:

### Обязательные

| Переменная | Описание |
|------------|----------|
| `SECRET_KEY` | Секретный ключ Django. Сгенерируйте случайную строку (минимум 50 символов). Пример генерации: `python3 -c "import secrets; print(secrets.token_urlsafe(50))"` |
| `YOUTUBE_API_KEY` | Ключ для получения данных с YouTube. Получается бесплатно (см. ниже). |

### Google OAuth (вход через Google)

| Переменная | Описание |
|------------|----------|
| `GOOGLE_CLIENT_ID` | Client ID из Google Cloud Console. Нужен для кнопки "Войти через Google". |

Как получить:
1. Зайдите на https://console.cloud.google.com/
2. Создайте проект (или откройте существующий)
3. Перейдите в **APIs & Services → Credentials**
4. Нажмите **Create Credentials → OAuth 2.0 Client ID**
5. Тип приложения: **Web application**
6. В поле **Authorized JavaScript Origins** добавьте: `http://localhost:5173`
7. Скопируйте **Client ID** — он идёт в обе переменные (`GOOGLE_CLIENT_ID` в бэкенде и `VITE_GOOGLE_CLIENT_ID` во фронтенде)

### Email (для подтверждения регистрации)

При регистрации платформа отправляет письмо с подтверждением. Для этого нужна почта Gmail с включённым доступом для приложений.

| Переменная | Описание |
|------------|----------|
| `EMAIL_HOST_USER` | Ваш Gmail-адрес (например, `example@gmail.com`) |
| `EMAIL_HOST_PASSWORD` | **Не обычный пароль от Gmail**, а специальный "пароль приложения" |
| `EMAIL_FROM` | Имя и адрес отправителя (можно то же, что `EMAIL_HOST_USER`) |
| `FRONTEND_URL` | Адрес фронтенда — вставляется в ссылку в письме. Локально: `http://localhost:5173` |

Как получить пароль приложения Gmail:
1. Зайдите в Google-аккаунт → **Безопасность**
2. Включите **Двухэтапную аутентификацию** (если ещё не включена)
3. В поиске настроек найдите **"Пароли приложений"**
4. Создайте новый пароль, выберите приложение "Почта"
5. Скопируйте 16-значный пароль (с пробелами) — вставьте как есть

### YouTube API

| Переменная | Описание |
|------------|----------|
| `YOUTUBE_API_KEY` | Ключ YouTube Data API v3 |

Как получить:
1. Зайдите на https://console.cloud.google.com/
2. Перейдите в **APIs & Services → Library**
3. Найдите **YouTube Data API v3** и включите его
4. Перейдите в **APIs & Services → Credentials → Create Credentials → API Key**
5. Скопируйте ключ

### Дополнительные (для продакшна)

Эти переменные нужны только при деплое на сервер, локально можно не заполнять:

| Переменная | Описание |
|------------|----------|
| `DEBUG` | `True` для разработки, `False` для продакшна |
| `DATABASE_URL` | URL базы данных PostgreSQL (для продакшна) |
| `ALLOWED_EXTRA_HOSTS` | Дополнительные хосты (домен сервера) |
| `CORS_EXTRA_ORIGINS` | Дополнительные разрешённые источники запросов (URL фронтенда на сервере) |
| `CSRF_EXTRA_ORIGINS` | Дополнительные разрешённые CSRF-источники |

## Панель управления

Через панель управления (http://localhost:8000/admin) можно:

- Добавлять **каналы** — вставить ссылку на YouTube-канал, данные (название, подписчики, аватар) подтянутся автоматически
- Добавлять **плейлисты** — вставить ссылку на YouTube-плейлист, заполнить описание и детали курса
- Добавлять **видео** — вставить ссылку на YouTube-видео
- Управлять **разделами** на главной странице (персонализированные карусели)
- Управлять **тегами** (Python, JavaScript и т.д.) и привязывать их к контенту
- Просматривать список **пользователей** и их онбординг-данные

## Частые вопросы

**Сервер не запускается — ошибка про порт?**
Значит порт 8000 занят другой программой. Запустите на другом порту:
```bash
poetry run python3 manage.py runserver 8001
```
Тогда в файле `front_end/.env` добавьте:
```
VITE_API_TARGET=http://localhost:8001
```

**Изображения не загружаются?**
Убедитесь что бэкенд запущен — фронтенд берёт медиафайлы с него.

**Забыли пароль администратора?**
```bash
cd back_end
poetry run python3 manage.py changepassword <имя_пользователя>
```

**Письма при регистрации не приходят?**
Проверьте что `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` заполнены в `.env`. Убедитесь, что используется пароль приложения Gmail, а не обычный пароль. Проверьте папку "Спам".

**Кнопка "Войти через Google" не работает?**
Убедитесь что `GOOGLE_CLIENT_ID` заполнен в `back_end/.env` и `VITE_GOOGLE_CLIENT_ID` — в `front_end/.env`. Проверьте, что в Google Cloud Console добавлен `http://localhost:5173` в Authorized JavaScript Origins.
